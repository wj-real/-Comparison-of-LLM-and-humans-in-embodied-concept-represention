# Comparison-of-LLM-and-humans-in-embodied-concept-represention

This repository contains the scripts for calling the LLMS, organized data, and analysis code used to generate the results reported in the main text ans supplementary materials for the study “Large Language Models Align with Humans in Static Concept Representations but Diverge in Contextual Flexibility and Cross-dimensional Integration.”
